# How Are These Free?

A reference page listing free operating systems, tools and creative software,
grouped by *why* they are free: open source, free proprietary, or open
standard / public domain.

Plain HTML, CSS and JavaScript, plus a local set of icons. No build step.

## Deploying

This folder is the entire site. `index.html` is the entry point, so it can be
published directly with GitHub Pages (Settings → Pages → Deploy from branch →
`main` / `/root`).
